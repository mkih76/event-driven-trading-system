# 事件驱动交易分析系统项目

## 一、项目背景

随着全球地缘政治事件频发、金融市场波动加剧，传统的基本面分析和技术分析已难以满足投资者对突发事件快速响应与精准决策的需求。国际重大事件（如军事冲突、贸易制裁、能源危机等）往往通过产业链传导路径，在数小时至数天内波及关联行业与标的，形成显著的交易机会与风险。

当前市场痛点：
- 事件分析依赖人工研判，响应滞后（通常需要数小时至数天）
- 缺乏系统化的产业链传导分析框架，难以量化事件影响
- 投资信号生成主观性强，缺少可解释的推理链条
- 传统研报覆盖范围有限，无法覆盖中小市值标的与新兴事件

本系统旨在通过大语言模型（LLM）自动化完成从"事件输入"到"投资信号输出"的完整链条，实现分钟级事件响应与产业链传导分析。

## 二、项目范围

### 2.1 主要功能模块

| 模块 | 功能描述 |
|------|----------|
| 事件理解 | LLM 自动识别事件类型、核心实体、市场情绪与事件强度 |
| 产业链传导分析 | 推理事件在产业链中的传导路径（成本传导、需求传导、替代效应） |
| 交易信号生成 | 基于传导分析生成做多/做空信号及置信度 |
| 可视化展示 | SVG 交互式传导图谱、情绪仪表盘、历史回测 |
| 流式分析 | SSE 实时展示 LLM 推理过程 |
| RAG 增强 | 实时市场数据上下文注入，提升分析准确性 |

### 2.2 技术边界

- **输入**: 自然语言描述的国际事件（标题+可选详细内容）
- **输出**: 产业链传导路径、交易信号、置信度与推理依据
- **支持场景**: 股票市场（A/H股）投资分析，衍生品策略辅助
- **部署方式**: Docker 容器化，支持私有化部署与云端 SaaS
- **不包含**: 交易执行、账户管理、风险敞口监控

## 四、技术架构

### 4.1 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                     用户层 (Web UI)                       │
│         事件输入 → 流式展示 → 传导图谱 → 交易信号           │
└─────────────────────────────────────────────────────────┘
                              ↕
┌─────────────────────────────────────────────────────────┐
│                    API 网关层 (Nginx)                      │
└─────────────────────────────────────────────────────────┘
                              ↕
┌─────────────────────────────────────────────────────────┐
│                  后端服务层 (FastAPI)                      │
│  事件理解 → 传导分析 → 信号生成 → RAG 增强                  │
└─────────────────────────────────────────────────────────┘
                              ↕
┌─────────────────────────────────────────────────────────┐
│                LLM 层 (SiliconFlow / OpenAI / Claude)     │
└─────────────────────────────────────────────────────────┘
```

### 4.2 技术选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | Next.js 14 + TypeScript + Tailwind CSS | SSR/SSG 支持，TypeScript 保障稳定性 |
| 后端 | FastAPI + Python 3.11 | 异步高性能，Pydantic 类型保障 |
| LLM | SiliconFlow（推荐）/ OpenAI / Claude / Ollama | 多提供商热备，降级机制 |
| 数据库 | SQLite（本地）/ Redis（可选缓存） | 轻量化部署 |
| 部署 | Docker + Docker Compose + Nginx | 一键部署，容器化运维 |

## 六、验收标准

- 系统在标准配置（2核4G）下完成事件分析响应时间 ≤ 10秒（不含 LLM 延迟）
- 流式分析（SSE）正常展示三阶段推理过程
- SVG 传导图谱正确渲染任意长度传导链（1-10步）
- 多 LLM 提供商之间正常切换，故障时自动降级
- Docker 容器在 Ubuntu 20.04+ 正常启动并通过健康检查
- 前端在 Chrome/Firefox/Safari 最新版本下正常展示
